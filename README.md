# 🏆 Sports Event Management Platform – Portfolio

Welcome to the portfolio of our **Sports Event Management Website Project**. This document presents the evolution of the project across **four semesters**, highlighting the technologies, concepts, and improvements implemented over time.

---

## 📚 Semester 1 – Programming Foundations

In the first semester, we built the fundamental knowledge required for software development. The focus was on understanding programming logic and basic web structure.

**Key topics:**

* Introduction to programming (variables, conditionals, loops)
* Basic algorithms and problem-solving
* HTML fundamentals (structure of a web page)
* Introductory CSS for simple styling

**Project progress:**

* Creation of static web pages
* Basic layout for the sports event website
* Simple navigation structure

---

## 💻 Semester 2 – Object-Oriented Programming & Web Design

During the second semester, we expanded our skills into structured programming and improved the visual design of the platform.

**Key topics:**

* Object-Oriented Programming (OOP)
* Intermediate HTML & CSS (responsive design)
* Introduction to JavaScript
* Version control basics (Git)

**Project progress:**

* Improved UI/UX design
* Responsive layout for multiple devices
* Basic interactivity using JavaScript
* Modular code organization

---

## 🌐 Semester 3 – Backend Development & Databases

In this stage, we introduced backend logic and database management to make the application dynamic and functional.

**Key topics:**

* Server-side programming fundamentals
* Relational databases (SQL)
* CRUD operations (Create, Read, Update, Delete)
* Client-server architecture

**Project progress:**

* User registration and login system
* Event creation and management features
* Database integration for storing users and events
* Basic authentication

---

## 🚀 Semester 4 – Modern Web Development (NoSQL & REST APIs)

In the fourth semester, we adopted modern technologies to scale and enhance the application.

**Key topics:**

* NoSQL databases (e.g., MongoDB)
* RESTful API development
* Advanced JavaScript (ES6+)
* Frontend-backend integration
* API consumption

**Project progress:**

* REST API for managing sports events
* Integration with NoSQL database
* Dynamic frontend using JavaScript and APIs
* Improved performance and scalability
* Separation of frontend and backend architecture

---

## 🎯 Project Goal

To develop a scalable and user-friendly platform that allows users to:

* Create and manage sports events
* Register participants
* View event details in real time
* Ensure efficient data handling and performance

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js (or similar)
* **Databases:** SQL (early stages), NoSQL (MongoDB)
* **Tools:** Git, REST APIs

---

## 📈 Conclusion

This project reflects a progressive learning journey from basic programming concepts to advanced web development practices. Each semester contributed essential knowledge that shaped the final product into a modern, functional web application.
